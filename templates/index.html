Como funciona a operação em segundo plano?

Assim como o ManyChat oficial, este sistema opera de forma desacoplada: o servidor gerencia o fluxo, os comentários são lidos em segundo plano e as mensagens são enviadas respeitando delays anti-spam humanizados (entre 15 e 30 segundos). Para funcionar 24h sem interrupção mesmo quando você fechar seu computador, consulte a aba "Rodar c/ PC Desligado".

Como rodar 24 Horas por Dia com o Computador Desligado

Para que o seu robô responda comentários e envie directs sem depender do seu notebook ligado, o programa foi preparado para ser hospedado gratuitamente ou por centavos em plataformas Cloud (Render, Railway, Fly.io ou VPS).

1

Hospedar no Render (Recomendado)

O Render possui plano gratuito e roda aplicações Flask / Python direto do GitHub.

  1. Crie uma conta gratuita em render.com.
  2. Crie um repositório no seu GitHub com os arquivos desta pasta.
  3. No Render, clique em New + Web Service e selecione o repositório.
  4. Comando de Inicialização: gunicorn web_app:app
  5. Pronto! Você terá um link próprio (ex: https://seu-bot.onrender.com) que você pode abrir até pelo celular!
2

Hospedar no Railway.app

O Railway detecta automaticamente o Procfile e o Dockerfile que já deixamos prontos na pasta.

  1. Acesse railway.app e faça login com seu GitHub.
  2. Clique em New Project -> Deploy from GitHub repo.
  3. O Railway iniciará o bot instantaneamente.
  4. Basta clicar em "Ativar Monitoramento 24/7" no seu dashboard online e desligar seu computador tranquilamente!
